# Моя библиотека

Личная библиотека и читательский дневник на русском языке. React 19, TypeScript, Vite, Tailwind CSS и Lucide React. Без сервера, регистрации и платных API.

## Запуск

Нужен Node.js 22.12+ (проверено на Node.js 24) и npm.

```sh
cd /workspace/library
npm ci
npm run dev
```

Vite слушает порт 5173 на всех интерфейсах. Для остановки — Ctrl+C.

```sh
npm test           # проверки схемы данных, валидации, статистики и хранения
npm run build     # TypeScript и production-сборка в dist/
npm run preview   # локальная проверка production-сборки, порт 4173
```

Браузерные сценарии: запустите dev-сервер и `npm run test:e2e` в другом терминале. В облачной среде используется установленный `/usr/bin/chromium`. На другой машине установите Chromium (`npx playwright install chromium`) и задайте `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` либо уберите системный путь в `playwright.config.ts` для использования браузера Playwright.

## Возможности

- Каталог: поиск, фильтры по статусу/жанру/оценке, сортировка, избранное.
- Добавление, редактирование и удаление книг с каскадным удалением цитат после подтверждения.
- Прогресс чтения, ручные даты, оценка, впечатления и собственные жанры.
- Цитаты, связанные с книгами: редактирование, поиск, фильтры, избранное и копирование (в защищённом контексте).
- Итоги по выбранному году: завершённые книги, известные страницы и оценки, месяцы, жанры и динамика по годам.
- Годовые цели, экспорт всех данных и проверяемый импорт с подтверждением замены.
- Мобильная навигация и подготовка к установке на домашний экран iPhone.

## Хранение и резервные копии

Источник данных — `localStorage`, ключ `moya-biblioteka.v1`. Четыре демонстрационные книги создаются только при отсутствии ключа. Удалённые книги не восстанавливаются автоматически. Даты завершения, оценки и цитаты в демонстрационных данных отсутствуют. Статистика не подменяется демонстрационными числами.

Экспорт включает `version: 1`, дату экспорта, книги, цитаты и годовые цели. Автор, жанр, статус, впечатления и избранное входят в запись книги. Импорт проверяет поля, даты, пределы страниц, уникальность ID и связи цитат; повреждённый файл не изменяет библиотеку. При повреждении сохранённых данных исходная строка остаётся нетронутой и доступна для скачивания в настройках; запись новых данных блокируется до явного восстановления.

Данные не синхронизируются между устройствами. Очистка данных сайта удалит библиотеку — сохраняйте резервные копии. Нет полноценного офлайн-кэша: первый запуск и загрузка внешних обложек требуют сети. Шрифты включены в сборку; обложки загружаются с Open Library либо по пользовательским URL, при ошибке используется типографическая обложка.

`src/data.ts` отделяет модель, проверку, чтение, сохранение и расчёты от интерфейса; облачный адаптер хранения можно добавить без переписывания компонентов представления.

## Публикация и iPhone

Соберите проект командой `npm ci && npm run build`. Разместите содержимое `dist/` в корне любого статического HTTPS-хостинга (например, Netlify или Vercel). Настройки: build command `npm run build`, output directory `dist`, Node.js 24. Секреты и серверная база данных не нужны. Сборка предполагает размещение в корне домена; для подпапки потребуется согласовать Vite base и пути manifest.

После публикации откройте адрес в Safari на iPhone → «Поделиться» → «На экран “Домой”». Manifest, PNG-иконки 192/512, apple-touch-icon 180, theme-color и standalone-метатеги включены. Установка на физический iPhone и внешняя публикация не выполняются автоматически при сборке.

## Структура

- `src/App.tsx` — навигация, общие данные и основные страницы.
- `src/data.ts` — типы, валидация, хранение, расчёты, импорт/экспорт.
- `src/components/UI.tsx` — доступные диалоги, обложки, рейтинги, пустые состояния.
- `src/components/Forms.tsx` — формы книг и цитат.
- `src/components/Insights.tsx` — статистика и настройки.
- `src/styles.css` — централизованные токены и адаптивная журнальная дизайн-система.
- `public/` — manifest и иконки; `tests/` — браузерные сценарии.

## Публикация через Vercel без командной строки

1. Откройте https://vercel.com/new и войдите через GitHub.
2. В разделе Import Git Repository найдите `avtaiaai-spec/library`. Если его нет, настройте доступ GitHub-приложения Vercel к выбранному репозиторию `library`.
3. Нажмите Import, затем Deploy. Файл `vercel.json` задаёт Vite, установку `npm ci`, сборку `npm run build` и папку `dist`; дополнительные переменные не нужны.
4. После успешной сборки откройте выданный Vercel адрес сайта. Автоматические обновления будут публиковаться при новых коммитах в подключённой production-ветке `main`.
5. Для установки на iPhone откройте именно постоянный адрес production-сайта в Safari → «Поделиться» → «На экран “Домой”».

Библиотека хранится отдельно для каждого адреса сайта и браузера. При смене домена перенесите данные через резервную копию. Выбор репозитория и подключение аккаунта выполняются владельцем в интерфейсе Vercel; наличие конфигурации само по себе не создаёт опубликованный сайт.
